# WhatsApp Chat Analyzer

A Python application that analyzes WhatsApp chat exports to generate insights about conversations, messaging patterns, and user activity.

## Features

- 📊 Parse WhatsApp chat export files (.txt)
- 📈 Visualize messaging trends and activity patterns
- 👥 Analyze individual user statistics (messages sent, media shared, etc.)
- 🕒 Identify peak messaging times
- 📱 Export analysis results
- 🎨 Interactive dashboard with Streamlit

## Tech Stack

- **Language**: Python
- **Framework**: Streamlit, FastAPI
- **Libraries**: pandas, matplotlib, seaborn, regex
- **Data Processing**: JSON/CSV export

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
streamlit run app.py
```
